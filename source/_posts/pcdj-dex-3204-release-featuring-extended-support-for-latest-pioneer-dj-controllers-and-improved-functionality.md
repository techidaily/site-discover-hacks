## PCDJ DEX 3.20.4 Release Featuring Extended Support for Latest Pioneer DJ Controllers and Improved Functionality

[![](https://i1.wp.com/pcdj.com/wp-content/uploads/2023/03/DEX3204.jpg?resize=845%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2023/03/DEX3204.jpg?fit=1030%2C622&ssl=1 "PCDJ DEX 3.20.4 DJ Software")

**Download DEX 3.20.4! The new free update to our best DJ software includes support for additional Pioneer DJ controllers, automatic key mixing, upgrades to supported streaming services, and more.**

[About DEX 3 ![PCDJ DEX 3](https://i2.wp.com/pcdj.com/wp-content/uploads/2022/01/dex3-macbook-tidal.png?fit=300%2C169&ssl=1 "PCDJ DEX 3")](https://tools.techidaily.com/pcdj/products/)

Development has been at it once again in the PCDJ bat cave. DEX 3.20.4 just dropped, and includes support for a few top Pioneer DJ controllers as well as a new “Mix in Key Automatically” setting.

_What is does “Mix in Key Automatically” offer DJs?_

Automatic Key Match/Sync can be enabled in the Preferences/Settings window. When enabled, DJs can now also match the musical key of a song to another. This is done in a ‘smart’ way so as to apply as little pitch/key change to the song so it will still sound natural (formant preserving). Try it in DEX 3.20.4 if you want to mix tracks harmonically.

Also, a series of updates are included for the built-in streaming services, including the much requested “explicit lyrics \[E\]” track tags for Beatport, Beatsource, SoundCloud, TIDAL, and iTunes/Music. As always, the update includes minor bug fixes and performance improvements. We suggest all DEX 3 DJs update to 3.20.4.

### Everything New, Changed, and Fixed in DEX 3.20.4

* New controller: [Pioneer DDJ-1000](https://www.pioneerdj.com/en-us/product/controller/ddj-1000/black/overview/)
* New controller: [DDJ-1000SRT](https://www.pioneerdj.com/en-us/product/controller/ddj-1000srt/black/overview/)
* New controller: [DDJ-800](https://www.pioneerdj.com/en-us/product/controller/ddj-800/black/overview/)
* New controller: Pioneer [DDJ-FLX4](https://www.pioneerdj.com/en/product/controller/ddj-flx4/black/overview/)
* New controller: Pioneer [DDJ-FLX6](https://www.pioneerdj.com/en-us/product/controller/archive/ddj-flx6/dark-grey/overview/) (no merge fx or jog cutter support)
* Vestax Typhoon controller mapping improvements
* New setting: “Auto match musical key when beat sync/match”
* Added [Beatport/Beatsource](https://tools.techidaily.com/pcdj/products/): Guest/Preview mode for unsubscribed users. The anonymous users can listen to the LOFI previews and search catalog, genres and curated playlists.
* Added explicit lyrics \[E\] song markings for [Beatport](https://tools.techidaily.com/pcdj/products/), [Beatsource](https://tools.techidaily.com/pcdj/products/), [SoundCloud](https://tools.techidaily.com/pcdj/products/), [TIDAL](https://tools.techidaily.com/pcdj/products/), iTunes/Music
* Several fixes and improvements for the iTunes (Windows) integration
* Implemented getValue scripting actions: originalKey, currentKey, key | deckSyncKey, deckSyncKeyReset (controller script) + deck\_synckey, deck\_synckey\_reset (skin)
* Notify the user if a bad/corrupted file was loaded (UI message: “errors while decoding track”)
* After the first decoding error we only output silence thus preventing any possible crashes with further decoding errors
* Fixed buffer overflow causing crash in Windows
* Various small fixes and improvements
